# MCDM GPU 스케줄링 알고리즘

**Multi-Criteria Decision Making (MCDM)** 기반의 이기종 GPU 클러스터 스케줄링 알고리즘입니다.  
단순히 가장 빠른 GPU를 고르는 것이 아니라, **4가지 기준**에 가중치를 달리하여 동시에 평가한 후 최적의 GPU를 결정합니다.

---

## 📐 알고리즘 입출력 및 목표

![MCDM 알고리즘 입출력](images/mcdm_io.png)

| 입력 | 설명 |
|------|------|
| **G** = {g₁, g₂, ..., gₘ} | 이기종 GPU 클러스터 (서로 다른 아키텍처/시장세그먼트) |
| **W** = {w₁, w₂, ..., wₙ} | 작업 대기열 리스트 |
| **P ∈ ℝⁿˣᵐ** | 처리량 행렬 — Pᵢⱼ는 GPU gⱼ에서 작업 wᵢ 실행 시 처리량 (samples/sec) |

**목표:** 자원 활용을 최적화하면서 비용을 최소화하는 할당 함수 **φ : W → G** 를 찾는다.

---

## 🔢 점수 계산 방식

![점수 계산 공식](images/mcdm_scores.png)

### 1. 성능 점수 (Performance Score, S_perf)
특정 작업에 대해 최고 성능 GPU 대비 정규화된 처리량 점수.

$$S_{\text{perf}}(w_i, g_j) = \frac{P_{ij} - P_{i,\min}}{P_{i,\max} - P_{i,\min}} \times 100$$

### 2. 자원 적합도 점수 (Resource Fit Score, S_fit)
SM 사용률과 메모리 사용률이 **최적 범위**에 얼마나 잘 맞는지 평가.  
과잉 프로비저닝(H200이 추론 작업에 메모리 2% 사용)과 과소 프로비저닝(RTX 3090에서 OOM 위험) 모두를 패널티로 반영.

$$S_{\text{fit}} = \frac{S_{\text{fit}}^{\text{SM}} + S_{\text{fit}}^{\text{mem}}}{2}$$

| 구간 | SM 최적 범위 | 메모리 최적 범위 |
|------|------------|--------------|
| 최적 | 75% ~ 90% | 55% ~ 75% |

### 3. 비용 효율 점수 (Cost Efficiency Score, S_cost)
달러당 처리량을 전체 GPU 중 최대값으로 정규화.

$$S_{\text{cost}}(w_i, g_j) = \frac{P_{ij}/c_j}{\max_{g_k \in \mathcal{G}}(P_{ik}/c_k)} \times 100$$

### 4. 전력 효율 점수 (Power Efficiency Score, S_power)
와트당 처리량을 전체 GPU 중 최대값으로 정규화.

$$S_{\text{power}}(w_i, g_j) = \frac{P_{ij}/\text{TDP}_j}{\max_{g_k \in \mathcal{G}}(P_{ik}/\text{TDP}_k)} \times 100$$

---

## ⚖️ 가중치 및 최종 점수

$$S_{\text{total}}(w_i, g_j) = \sum_{d \in \{\text{perf, fit, cost, power}\}} w_d \cdot S_d$$

| 기준 | 가중치 | 의미 |
|------|--------|------|
| w_perf | **0.20** | 성능 |
| **w_fit** | **0.50** | 자원 매칭 (가장 중요) |
| w_cost | **0.20** | 비용 효율 |
| w_power | **0.10** | 전력 효율 |

> 자원 매칭(w_fit = 0.50)을 가장 중요하게 반영하여, 단순히 빠른 GPU가 아니라 작업 크기에 GPU가 잘 맞는지를 우선적으로 고려합니다.

## 📝 구현 참고사항

- **메모리 사용률 점수**: 논문에 수식이 없어 SM 사용률 점수 구조를 메모리 최적 범위(55~75%)에 동일하게 적용
- **전력 효율 점수**: 논문에 수식이 없어 비용 효율 점수 방식을 와트당 처리량에 동일하게 적용 (정규화 포함)
- **변경 가능 파라미터**: 가중치 조정, 성능 점수 정규화 방식, 자원 적합도 최적 구간 비율
